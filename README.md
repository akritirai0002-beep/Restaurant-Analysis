# 🍽️ Restaurant Performance & Customer Analysis Dashboard

An interactive data analytics and business intelligence project exploring restaurant operations, customer dining patterns, pricing tiers, and overall performance.

This repository features the raw dataset, structured assignment documentation, analytical question briefs, and an interactive **Power BI** dashboard (`.pbix`).

---

## 📌 Project Overview

Understanding dining preferences, customer ratings, average order values, and operational efficiency is key to improving hospitality management. 

This project explores:
- **Dining Trends & Cuisine Preferences:** Analyzing popular cuisines, order volume, and dining categories.
- **Rating & Pricing Patterns:** Examining correlations between price tier, service ratings, and customer satisfaction.
- **Operational Metrics:** Assessing location-based and capacity-driven performance across restaurants.
- **Structured Business Inquiries:** Providing data-backed solutions to targeted business questions outlined in the project brief.
